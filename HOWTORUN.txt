# BitChest - Quick Start Guide

## Prerequisites
- PHP 8.2+, Composer, Node.js 18+, npm, Git

## One-Time Local Setup
```bash
# Backend
cd backend
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate:fresh --seed

# Frontend
cd ../frontend
npm install
```

## Run Locally (2 Terminals)

| Terminal | Command | Purpose |
|----------|---------|---------|
| 1 | `cd backend && php artisan serve` | API at http://localhost:8000 |
| 2 | `cd frontend && npm run dev` | Frontend at http://localhost:3000 |

*(Optional)* If you want real-time private user notifications via WebSocket:
`cd backend && php artisan reverb:start`
